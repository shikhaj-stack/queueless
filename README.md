# Queueless Bhopal

Next.js and Supabase backend featuring a real-time virtual queue engine and automated Claude Code pipelines to verify government service data.

Includes interactive Form Filling Tutorials, annotated screenshot walkthroughs, Field Inspector, and Practice Simulator to ensure error-free government portal applications.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features
- **Visual Form Filling Tutorials & Walkthroughs (`/tutorials`)**: Interactive screenshot guides with field hotspots and validation simulator.
- **Virtual Queue System**: Live token tracking and rolling wait-time estimates.
- **Bilingual Interface**: Full English and Hindi support.
- **Service Verification**: Up-to-date requirements, eligibility, fee structures, and document scan helpers.
